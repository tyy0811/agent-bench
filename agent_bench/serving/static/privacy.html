Privacy note

This demo runs only in your browser and clears on reload. Direct API requests may be processed by an external AI provider and logged for security and debugging, so please do not submit personal data.

API data handling

Direct calls to /ask or /ask/stream send the question and relevant conversation context to the selected provider. Agent-bench records question text, a hashed client IP, and safety results in its audit log. If you supply a session ID, it also saves the question and answer for conversation history. The service also records aggregate operational metrics. Agent-bench does not use this data for profiling or model training; external providers process submitted content under their own terms.
